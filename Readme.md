## 3. Abstract

The AI Resume Screening System is an application designed to automate and simplify the resume screening process using Artificial Intelligence.

The system aims to analyse resumes, extract important information such as skills, educational qualifications and work experience, and compare candidate profiles with the requirements mentioned in a job description.

By using Artificial Intelligence and Natural Language Processing (NLP), the system helps identify suitable candidates based on their qualifications and skills.

The main objective of this project is to reduce manual effort, save time and improve the efficiency of the recruitment process.

## 4. Objectives

- To automate the resume screening process using Artificial Intelligence.
- To extract important information from resumes.
- To identify candidate skills and qualifications.
- To compare resumes with job descriptions.
- To assist recruiters in identifying suitable candidates.
- To reduce manual effort and time in recruitment.
